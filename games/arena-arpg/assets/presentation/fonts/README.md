# Default game font

`NotoSans.ttf` is the variable Noto Sans font from Google Fonts.
It provides Latin, Greek, and Cyrillic glyphs. It does not provide complete Unicode coverage.
Games need additional fallback fonts for other scripts, including Chinese.

The Arena client and character preview embed this file.
Startup does not depend on installed system fonts or working-directory font paths.
Text uses the regular weight and normal width.

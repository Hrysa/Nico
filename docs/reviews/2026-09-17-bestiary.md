# Animated Bestiary monsters

This records initial integration and its validation, followed by the correction
that removed presentation-only injury. The initial native captures include hit
reactions; current behavior is specified in the [character contract](../plans/2026-09-17-character-definitions.md).

Grunts use Imp; brutes use Puglin in both open-world and arena clients.
Models and clips are immutable shared assets per type, with an independent player
per entity. Arena players reset when an actor slot changes type; world instances
are keyed by stable object ID and discarded on removal or connection epoch change.
The renderer budgets complete imported actors before submitting their meshes.
Embedded monster weapons use their authored skinning, while the hero retains its
optional attached sword. Headless logic, collision, damage, and timings are unchanged.

At initial integration, Library 2 supplied idle, pursuit, attack, and hit; RPG
supplied death. The initial six-motion format also bound dodge, although monster
logic does not dodge. The follow-up below removes hit playback. Content preparation, licenses, and remaining contact/shading limitations are
documented in the [monster notice](../../games/arena-arpg/assets/presentation/characters/monsters/README.md).
Both `client_characters` and per-frame `actor_animations` expose the new content.

Validation on Windows, 2026-09-17:

- All 36 client tests passed, including loading both real Bestiary models,
  retargeting every motion at five positions, checking finite palettes and bounds,
  independent player time, embedded weapons without an extra sword draw, and the
  existing hero grip/contact regressions.
- Client build, all-target client Clippy with warnings denied, and formatting
  passed. The existing incremental-cache access-denied notes remained nonfatal.
  A server rebuild encountered a locked executable; the existing server was left
  untouched and the unchanged server binary was used for isolated validation.
- The two-client world smoke passed movement, dodge, cooperative combat,
  loot/equipment, death/respawn, reconnect, and server restart. Evidence is in
  `target/bestiary-world-evidence/report.json`. Client instances
  `3104-18d61031621f510c-2` (PID 29504) and `3104-18d61031621f510c-3` (PID 32456)
  were discovered and PID-checked. The inspected `cooperative-combat.png` shows
  the Puglin fight and camp Imps. Separately sampled state reports Puglin attack
  playback (three model draws); the equipped capture's state reports its death.
- An additional arena capture used instance `33760-18d6103f9a8174b8-1`, PID 26312.
  Its inspected capture shows three Imps; separately sampled state reports five
  skinned model draws per Imp. Evidence is in `target/bestiary-arena-evidence/`.
- Automated control stopped, both test runs closed their windows, and owned
  processes exited. No user-observed desktop success is claimed. Captures and
  before/after snapshots are separate samples, not same-frame assertions.

These checks establish model/animation integration and retained gameplay behavior.
They do not establish full material fidelity or final foot/weapon-contact polish.

## Follow-up: remove presentation-only injury

Removed health-loss-triggered hit playback from all characters and removed hit
bindings from the five-motion game contract. There is no authoritative injury/stun
state. Nonlethal damage therefore preserves idle, movement, attack, or dodge
playback; zero health still selects death. Original imported animation packs are
unchanged. Regression coverage compares damaged and undamaged action playback.
The earlier native captures above predate this correction.
All 37 client tests, client all-target Clippy with warnings denied, and formatting
passed after the correction. Native visual tests were not repeated for this removal.

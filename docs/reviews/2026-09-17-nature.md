# Meadow Nature integration

Meadow now loads seven prepared Quaternius Nature models through a client-only
world visual definition. Two rock models replace collision-box visuals; nine
trees share ground anchors with authoritative trunk colliders. Forty-four small
plants decorate the settlement and camp margins. Houses remain placeholders.

The server zone supplies stable obstacle IDs, positions, and box dimensions.
The client maps IDs to local model assets; server gameplay does not load models.
Static geometry and palettes are cached, whole placements are frustum culled,
and decorative draws use capacity remaining after actors. The configuration and
material/collision limitations are described in the
[scenery guide](../../games/arena-arpg/assets/presentation/worlds/README.md).

Validation on Windows, 2026-09-17:

- All 39 client and 63 shared all-feature tests passed. New checks cover server
  obstacle fitting, tree grounding, zone replacement, shared render resources,
  draw limits, stable-ID uniqueness, and blocked tree locations. The collision
  test was subsequently extended to verify movement stops at the trunk and passed.
- Strict workspace all-target Clippy passed. Native binaries were built under
  `target/bridge-validation` to avoid replacing running user executables.
- The two-client native scenario passed scenery inspection, movement, dodge,
  cooperative combat, loot/equipment, death/respawn, reconnect, and server restart.
  Evidence is in `target/nature-world-evidence/report.json`. Client instances
  `28684-18d6125e913226d4-2` (PID 10556) and
  `28684-18d6125e913226d4-3` (PID 16640) were discovered and PID-checked.
- Inspected `-2-movement.png` and `cooperative-combat.png` from the first client
  show imported scenery with an open main path. Separately sampled state reports
  seven loaded models, 11 solid model placements, 44 decorations, and 67–79 total
  draws across the captured scenarios. Captures and state are not same-frame data.
- Automated control stopped, test windows closed, and owned processes exited.
  No user-watched desktop confirmation was collected or claimed.

The existing unlit/base-color pipeline does not reproduce full source materials,
normal mapping, foliage shaders, or shadows. Rock collision remains a fitted box;
tree collision covers the trunk rather than the canopy. These are deliberate
limits of this integration, not mesh-accurate collision or final art acceptance.
